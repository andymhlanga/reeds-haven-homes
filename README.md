# Reeds Haven Homes website

Static, responsive website ready for GitHub and Netlify. No paid theme, framework, or build step required.

## Publish
1. Create a GitHub repository, e.g. `reeds-haven-website`.
2. Upload all files from this folder to the repository root (not the ZIP itself).
3. In Netlify choose **Add new project → Import an existing project → GitHub**, authorize and select the repository.
4. Build command: leave blank. Publish directory: `.`. Deploy.
5. Under Netlify **Domain management**, add the domain you purchase from GoDaddy. Follow the exact DNS records Netlify provides in your dashboard and configure them at GoDaddy. Enable HTTPS when DNS resolves.
6. In Netlify, enable form detection if required, deploy again, and set email notifications for submissions. Test a submission.
7. Any future commit to the connected GitHub branch automatically redeploys the site.

## Before public launch
- Review all statements about operations, referrals and services for accuracy.
- Replace the text-based RH monogram with your official logo if available.
- Add a public business email or phone only once confirmed.
- Add a privacy policy appropriate to your operations and form collection; avoid collecting health or client details in the general form.
- Test mobile navigation, accessibility, contact form, domain and HTTPS.
